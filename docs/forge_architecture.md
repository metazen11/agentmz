# Forge Architecture Reference

> Generated by Codex (gpt-5.1-codex-mini) via Claude orchestration - 2026-02-01

## Forge Directory Map

| File | Purpose |
|------|---------|
| `forge/__init__.py` | Package metadata (docstring + `__version__`) |
| `forge/__main__.py` | `python -m forge` entry point, dispatches to `forge.cli.app` |
| `forge/app.py` | Textual TUI application (status bar, chat log, @ file autocomplete, clipboard, command palette, background agent runner) |
| `forge/cli.py` | Typer-based CLI/REPL with built-in commands, launches ForgeApp, supports single-prompt mode |
| `forge/forge` | Bash wrapper that boots virtualenv, sets PYTHONPATH, defaults workspace to cwd |
| `forge/forge.tcss` | Textual stylesheet for screen, status bar, chat region, prompt input, autocomplete |

## Support Modules

| File | Purpose |
|------|---------|
| `forge/config.py` | `~/.forge/config.toml` management, `/config` handler, Ollama model discovery |
| `forge/subagent.py` | Claude subagent wrapper (session persistence, one-shot delegate, CLI isolation) |
| `forge/agent/runner.py` | Agent runner binding `scripts/agent_cli.py` tools, streams status to UI |
| `forge/agent/session.py` | Session tracker for history/token stats |
| `forge/tools/registry.py` | Workspace-aware tool registry (save/load custom tools, LangChain conversion) |
| `forge/tools/explore.py` | Simple explore helper (prompts for search pattern) |

## Widgets

| File | Purpose |
|------|---------|
| `forge/widgets/chat_display.py` | Scrollable chat log widget |
| `forge/widgets/file_autocomplete.py` | @ file dropdown autocomplete |
| `forge/widgets/status_bar.py` | Running workspace/model/status display |
